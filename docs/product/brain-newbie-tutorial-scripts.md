## 怎么用这份剧本

每个镜头包含四部分，录制时照做即可：

- **截图**：这一镜录完后画面应该是什么样子（红框 = 后期要加的强调框）。
- **操作**：录屏时要做的动作，`「」` 里是要点击的按钮，代码块里是要输入的原文。
- **旁白**：配音口播稿，可直接照读（语速约每分钟 200–220 字）。
- **字幕 / 标注**：后期叠加的文字、箭头、红框。

AI 思考、生成的等待时间一律跳剪或加速，并在角落标注“已加速”。截图里如果出现产品缺陷（见附录 B），剧本里会注明“录制时怎么绕开”。

## EP00｜三分钟认识 BRAIN

**本集学会**：登录方式、界面三栏各是什么、八个工作台怎么切换、关掉窗口后 BRAIN 去哪了。

### 镜头 1｜登录（0:00–0:25）

![登录页](./tutorial-screenshots/ep01-01-login.png)

- **操作**：展示登录窗口，鼠标依次指「邮箱」「手机」两个页签和下方「支付宝扫码登录」；指一下底部的服务协议勾选框。
- **旁白**：第一次打开 BRAIN，会先看到登录页。可以用邮箱、手机号，也可以用支付宝扫码。记得勾选下面的服务协议。登录一次之后就会记住你，下次打开直接进入。
- **字幕 / 标注**：「邮箱 / 手机 / 支付宝 三种方式」。录制时邮箱打码。不要在演示账号上点“退出登录”。

### 镜头 2｜首次启动（0:25–0:40）

- **截图**：无（首次启动的初始化页只出现一次，录制时用一台新电脑现场拍）。
- **操作**：新装后第一次登录，停留在初始化进度页，等它自动进入主界面。
- **旁白**：第一次进来时，BRAIN 会花几十秒准备本地环境，比如数据目录和运行工具。进度走完会自动进入主界面，不需要你做任何设置。
- **字幕 / 标注**：「只有第一次需要等」。

### 镜头 3｜主界面三栏（0:40–1:20）

![主界面](./tutorial-screenshots/ep00-01-main.png)

- **操作**：停在首页不动，鼠标依次在左栏、中间输入框、右栏上缓慢划过。
- **旁白**：这就是 BRAIN 的主界面，一共三栏。左边是导航和你的项目、聊天记录；中间是和 AI 对话的地方，你想做什么，直接在这里说；右边是“项目资源”，AI 帮你做出来的文件、产物和任务都会出现在这里。
- **字幕 / 标注**：左栏「导航 + 项目」、中栏「对话」、右栏「项目资源」三个标签依次弹出。

### 镜头 4｜八个工作台（1:20–2:10）

![工作台菜单](./tutorial-screenshots/ep00-02-workspace-menu.png)

- **操作**：点击左上角当前工作台名称（图中为「场景学习探索」），展开菜单，鼠标从上到下划过八个选项。
- **旁白**：左上角这里可以切换工作台。BRAIN 按你要做的事情分成八个工作台：量化交易、游戏制作、视频制作、音乐创作、数据与决策、软件与自动化、文档创作，还有默认的场景学习探索。选哪个工作台，AI 就会带上那个领域的专业工具。
- **字幕 / 标注**：红框框住工作台按钮；右侧逐条弹出八个工作台名称。

### 镜头 5｜右栏会跟着工作台变化（2:10–2:40）

![数据工作台右栏](./tutorial-screenshots/ep03-02-data-home.png)

![量化工作台右栏](./tutorial-screenshots/ep04-01-quant-home.png)

- **操作**：先切到「数据与决策」停 2 秒，再切到「量化交易」停 2 秒。
- **旁白**：注意看右边，换了工作台，右栏的工具也跟着变。数据工作台有数据表格、清洗和图表；量化工作台有行情、组合和策略。
- **字幕 / 标注**：右栏标签页处加红框。

### 镜头 6｜关掉窗口，BRAIN 还在托盘里（2:40–3:00）

- **截图**：无（系统托盘属于用户桌面，录制时现场拍）。
- **操作**：点窗口右上角「×」关闭窗口；到屏幕右下角托盘找到 BRAIN 图标，右键展开菜单，停 2 秒；再双击图标回到主界面。
- **旁白**：点叉关掉窗口，BRAIN 并没有退出，而是躲到了右下角的托盘里，定时任务照样会跑。右键托盘图标，可以看到正在运行和最近的任务，也能新建任务或者彻底退出。双击图标就能把窗口叫回来。
- **字幕 / 标注**：托盘菜单依次标出「运行中」「最近任务」「新建任务」「打开 NewBrain」「退出」。结尾卡片「下一集：第一次对话」。

## EP01｜第一次对话：快速上手

**本集学会**：提问、调推理强度、加附件、权限、新建项目、查看生成的文件、处理审批。

### 镜头 1｜问第一个问题（0:00–0:30）

![输入问题](./tutorial-screenshots/ep01-02-type-question.png)

- **操作**：点击中间输入框，输入下面的问题，按回车发送。

```text
用三句话解释什么是复利，再举一个生活中的例子
```

- **旁白**：用起来和聊天一样简单。在中间的输入框里直接打字，按回车，就发出去了。
- **字幕 / 标注**：输入框红框；「回车发送，Shift + 回车换行」。

### 镜头 2｜看回答（0:30–0:55）

![AI 回答](./tutorial-screenshots/ep01-03-answer.png)

- **操作**：等回答出来，鼠标划过回答正文，再指一下左栏新出现的聊天记录。
- **旁白**：几秒钟 AI 就答完了。这条对话会自动保存在左边的“聊天”里，随时可以回来接着问。回答下面还有一排小按钮，下一集细讲。
- **字幕 / 标注**：箭头指向左栏新出现的聊天记录。

### 镜头 3｜推理强度（0:55–1:20）

![推理强度菜单](./tutorial-screenshots/ep01-04-model-menu.png)

![Optimize 子菜单](./tutorial-screenshots/ep02a-17-optimize-menu.png)

![速度子菜单](./tutorial-screenshots/ep02a-18-speed-menu.png)

- **操作**：点击输入框右下角「Auto·均衡 中」，展开菜单；先指上半部分的低 / 中 / 高 / 超高；再点「Optimize · 均衡」，展开“省钱 / 均衡 / 效果优先”；按 Esc 后重新打开菜单，点「速度」，展开“标准 / 快速”；最后按 Esc 关闭，不做修改。
- **旁白**：右下角这个按钮管三件事。第一是“推理强度”，分低、中、高、超高：日常问题用默认的“中”就够了，复杂的分析、写方案可以调高，AI 会想得更仔细，但也更慢。第二是“Optimize”，也就是自动选模型时偏向哪一边：“省钱”用更便宜的模型，“效果优先”用更强的模型，默认“均衡”。第三是“速度”：“快速”回得更快，“标准”更稳。新手全部保持默认就行。
- **字幕 / 标注**：「推理强度：简单问题低/中，复杂任务高/超高」「Optimize：省钱 / 均衡 / 效果优先」「速度：标准 / 快速」。

### 镜头 4｜加号菜单：附件和模式（1:20–1:50）

![加号菜单](./tutorial-screenshots/ep01-05-add-menu.png)

- **操作**：点击输入框左下角「＋」，鼠标依次划过「文件和图片」「挂载工作区文件夹」「目标」「计划模式」和下方插件列表。
- **旁白**：左下角的加号是个百宝箱。这里可以上传文件和图片，也可以把电脑里的一个文件夹挂进来让 AI 读；“目标”和“计划模式”适合大任务，下一集会演示；下面还有浏览器、Word、PDF 这些插件。其实最简单的办法是直接把文件拖进输入框。
- **字幕 / 标注**：「小技巧：文件直接拖进输入框」。

### 镜头 5｜权限：替我审批（1:50–2:20）

![权限菜单](./tutorial-screenshots/ep01-07-permission-menu.png)

- **操作**：点击「替我审批」，展示两个选项，确认仍选中「替我审批」。
- **旁白**：这里决定 AI 能自己做多少事。默认的“替我审批”最安全：普通操作 AI 自己处理，遇到有风险的动作，会停下来问你。“完全访问”不做限制，新手不建议打开。
- **字幕 / 标注**：「新手请保持：替我审批」。

### 镜头 6｜新建项目（2:20–2:50）

![添加项目菜单](./tutorial-screenshots/ep01-08-add-project-menu.png)

![命名项目](./tutorial-screenshots/ep01-09-name-project.png)

- **操作**：鼠标移到左栏「项目」一行，点右侧「＋」→「新建空白项目」，输入 `我的第一个项目`，点「保存」。
- **旁白**：如果一件事要做好几轮，比如写一份报告、分析一批数据，建议先建一个“项目”。项目会把相关的对话、文件和产物放在一起，不会和别的事混在一块。点项目旁边的加号，新建空白项目，起个名字就好。
- **字幕 / 标注**：「项目 = 一件事的文件夹」。

### 镜头 7｜在项目里让 AI 生成文件（2:50–3:30）

![项目中提需求](./tutorial-screenshots/ep01-10-project-chat.png)

![运行位置菜单](./tutorial-screenshots/ep01-14-run-mode-menu.png)

- **操作**：先点输入框下方的「本地模式」，展示“在本地处理 / 新工作树”后按 Esc；再在项目首页输入框输入下面的内容并发送。

```text
帮我做一份简洁的周报模板，包含本周完成、下周计划、风险与需要的支持三部分，保存成 Word 文档
```

- **旁白**：现在输入框上方写着“我们该在 我的第一个项目 中做什么”，说明接下来的对话都属于这个项目。输入框下面一排依次是：项目名、运行位置、分支。运行位置默认“在本地处理”，也就是直接改这个项目文件夹；“新工作树”会先复制一份再改，适合写代码的人，新手不用动。下面三张“连接消息传送 / GitHub / Linear”的卡片，点了会跳到设置里的 MCP 服务器页，目前没有一键连接，先不用管。我们让 AI 做一份周报模板，并且直接保存成 Word 文件。
- **字幕 / 标注**：框出输入框下方的项目名；「运行位置：新手保持“在本地处理”」。

### 镜头 8｜生成完成（3:30–3:55）

![生成完成](./tutorial-screenshots/ep01-11-artifact-done.png)

- **操作**：等回复完成，鼠标指向「文件变更」里的 `outputs/周报模板.docx`。
- **旁白**：完成了。AI 告诉我们文件保存在哪里、里面有哪几部分，最下面的“文件变更”列出了它新建的文件。
- **字幕 / 标注**：红框「文件变更」。左栏如果出现带“子 Agent 失败”标签的子线程，后期打码或口播说明（见避坑 1）。

### 镜头 9｜打开文件预览（3:55–4:15）

![打开产物](./tutorial-screenshots/ep01-12-open-artifact.png)

- **操作**：点击 `outputs/周报模板.docx` 链接，右侧打开预览。
- **旁白**：点一下文件名，右边就能直接预览，不用另外打开 Word。右上角还可以下载、用系统软件打开。
- **字幕 / 标注**：箭头指向预览区右上角的下载按钮。

### 镜头 10｜遇到审批怎么办（4:15–4:45）

![审批卡片](./tutorial-screenshots/ep01-13-approval-card.png)

- **操作**：展示一张审批卡片，鼠标先指卡片里的命令，再指「拒绝」「批准并继续」。
- **旁白**：有时候 AI 会弹出这样一张卡片，意思是“这一步有风险，需要你点头”。卡片里写着它要执行的具体命令。看得懂、确认没问题就点“批准并继续”；拿不准就点“拒绝”，然后告诉它换一种方式做。
- **字幕 / 标注**：「看清命令再批准」；结尾卡片「下一集：对话进阶」。

## EP02｜对话进阶：计划、目标、引用、排队

**本集学会**：计划模式、回答上的小按钮、修改问题、@ 引用别的对话、排队发消息（立即发送 / 编辑 / 删除）、语音听写现状、目标模式、上下文用量、停止生成、让 AI 上网查资料。

### 镜头 1｜加号菜单里的两种“大任务模式”（0:00–0:20）

![加号菜单](./tutorial-screenshots/ep02a-01-plus-menu.png)

- **操作**：点「新对话」，再点输入框左下角「＋」，指向「添加」分组里的「目标」和「计划模式」。
- **旁白**：上一集我们提到加号菜单里有“目标”和“计划模式”。这一集先来试试计划模式。
- **字幕 / 标注**：框出「目标」「计划模式」。

### 镜头 2｜计划模式：先想清楚再动手（0:20–1:00）

![计划模式](./tutorial-screenshots/ep02a-02-plan-mode-on.png)

![计划结果](./tutorial-screenshots/ep02a-03-plan-result.png)

- **操作**：点「计划模式」，输入框下方出现计划模式标记；输入下面的内容并发送，等回答完成后滚到预算表。

```text
帮我规划一个周末两天的杭州亲子游，预算 2000 元，孩子 6 岁
```

- **旁白**：打开计划模式后，AI 会先把事情拆成步骤、列清楚，再给你结果。你看，行程按天排好，最后还有一张预算表：合计大约 1830 元，留了 170 元余量，没有超预算。
- **字幕 / 标注**：框出“合计 约 1830 元”。

### 镜头 3｜回答下面的小按钮（1:00–1:40）

![回答操作](./tutorial-screenshots/ep02a-04-answer-actions.png)

![智能朗读](./tutorial-screenshots/ep02a-05-read-aloud.png)

![分叉结果](./tutorial-screenshots/ep02a-22-fork-result.png)

- **操作**：鼠标移到回答末尾，出现一排按钮，依次悬停「有帮助」「没有帮助」「分叉答案」「复制答案」「智能朗读」；点「智能朗读」，底部出现“正在朗读”条，再点一次停止。分叉只悬停讲解，**不要点**（原因见字幕）。
- **旁白**：鼠标移到回答下面，会出现一排小按钮。点赞、点踩帮助 AI 改进；“分叉”的本意是从这个回答另开一个分支继续聊，不影响原来的对话；“复制”一键复制全文；“智能朗读”会把回答读给你听，适合做饭、开车的时候。
- **字幕 / 标注**：五个按钮依次标名称。注意：这排按钮只在鼠标悬停时出现。第三张截图是实测点“分叉答案”的结果：左栏多了一条“……答案分叉”，但里面是空的，原来的问答没有带过来；在普通聊天里点分叉，新对话甚至不显示，画面还会跳到别的对话（见避坑 24）。录制时只讲按钮，不演示点击。

### 镜头 4｜改一改刚才的问题（1:40–2:00）

![编辑问题](./tutorial-screenshots/ep02a-06-edit-question.png)

- **操作**：鼠标移到自己发的那条消息上，指出下方「复制」「编辑」两个按钮。
- **旁白**：问题问得不够好？鼠标移到你自己的消息上，点“编辑”改一改再发，不用重新打一遍。
- **字幕 / 标注**：框出「编辑」。

### 镜头 5｜@ 引用另一段对话（2:00–2:50）

![@ 菜单](./tutorial-screenshots/ep02a-07-at-mention.png)

![引用卡片](./tutorial-screenshots/ep02a-08-at-chip.png)

- **操作**：在输入框输入 `@`，弹出“引用其它对话”列表，选「用三句话解释什么是复利……」；输入框上方出现引用卡片，接着输入下面的内容，先不要发送。

```text
结合这段复利的解释，帮我设计一个给 6 岁孩子讲零花钱的小故事，200 字以内
```

- **旁白**：之前聊过的内容，不用复制粘贴。输入一个 @，就能把另一段对话“引用”进来，AI 会带着那段内容一起思考。比如我们引用第一集讲复利的那段对话，让它编一个讲给孩子听的零花钱故事。
- **字幕 / 标注**：框出引用卡片。发送后用户气泡里会显示整段引用原文，画面较长，建议跳剪（见避坑 13）。

### 镜头 6｜AI 还在忙时，可以先排队（2:50–3:30）

![排队中](./tutorial-screenshots/ep02a-09-queue.png)

![排队消息的回答](./tutorial-screenshots/ep02a-10-at-answer.png)

- **操作**：按回车发送上一条；趁 AI 还在回答，立刻再输入下面的内容并回车，输入框上方出现“排队中 · 1”；等两条都回答完，滚动到最后。

```text
再补充三个适合亲子一起玩的储蓄小游戏
```

- **旁白**：AI 还在回答的时候，你想到新问题也可以直接发，它会进入“排队”，等这一轮结束自动接着发。你看，故事讲完后，三个储蓄小游戏也接着出来了。
- **字幕 / 标注**：框出「排队中 · 1」。

### 镜头 6（续）｜排队消息的三个按钮：立即发送、编辑、删除（3:30–4:10）

![排队列表](./tutorial-screenshots/ep02a-23-queue-actions.png)

![删掉一条后](./tutorial-screenshots/ep02a-24-queue-deleted.png)

![立即插入](./tutorial-screenshots/ep02a-25-send-now.png)

![插入后的结果](./tutorial-screenshots/ep02a-26-send-now-result.png)

- **操作**：发送第一条；趁 AI 在写，**每次先点一下输入框**，再依次输入第二、三条并回车，输入框上方出现“排队中 · 2”；点第二条右边的「×」删掉它；再点剩下那条右边的「↑」（悬停提示“立即插入当前运行”）；等回答完成，滚到文章里的龙舟规则段落。

```text
用 1000 字写一篇介绍端午节的科普短文，分成来历、习俗、各地差异三部分
```

```text
文章里再补充一段龙舟竞渡的规则
```

```text
最后加三道关于端午的小测验题
```

- **旁白**：排队的每条消息右边有三个小按钮。“×”是删掉，不想问了就删；铅笔是放回输入框再改改；向上的箭头是“立即发送”，AI 正在写的时候点它，这条要求会直接插进当前这一轮，不用等写完再返工。你看，我们插入了“补充龙舟竞渡规则”，文章里马上就多了一段比赛规则。

### 镜头 7｜目标模式：交给 AI 一件完整的事（4:30–5:40）

![打开目标](./tutorial-screenshots/ep02a-11-goal-on.png)

![目标执行中](./tutorial-screenshots/ep02a-12-goal-running.png)

![目标完成](./tutorial-screenshots/ep02a-13-goal-done.png)

- **操作**：点「新对话」，「＋」→「目标」，输入框下方出现「目标」标记；输入下面的内容并发送；等待完成后滚到“已完成的目标”卡片。

```text
整理一份 6 岁孩子的暑假阅读清单：10 本书，分成绘本和桥梁书两类，每本写一句推荐理由，最后保存成 Word 文档
```

- **旁白**：“目标”适合一件需要好几步才能做完的事。AI 会先定目标、拆步骤，一步一步做，每做完一步打个勾。最后这张“已完成的目标”卡片写得清清楚楚：定好书单、生成 Word 文档、验证文件确实存在，三步全部完成。

### 镜头 8｜上下文用量（5:40–6:10）

![上下文用量](./tutorial-screenshots/ep02a-14-context-meter.png)

- **操作**：指向输入框右下角「Auto·均衡」左边的小圆圈，悬停显示用量。

- **字幕 / 标注**：「圈快满了 → 新开对话」。

![停止按钮](./tutorial-screenshots/ep02a-15-stop-button.png)

- **操作**：输入下面的内容并发送；AI 开始回答后，发送按钮变成方形「停止」按钮，点一下。

```text
写一篇 3000 字的科普文章，主题是太阳系八大行星，每颗行星一节
```

![联网搜索失败](./tutorial-screenshots/ep02a-27-web-search-failed.png)

- **操作**：新开一条对话，输入下面的内容并发送。等思考面板里出现搜索工具；本轮会全部失败，停在失败结果上，不要剪成“已经查到了”。

```text
帮我搜索一下最新的社区咖啡店短视频营销案例，用三句话总结，并给出出处链接。
```

- **旁白**：想查现在网上的说法，直接让它搜索。它会自己去调联网搜索，再把带来源链接的结果告诉你。这一轮没有查到：不带“最新、今天、新闻”这类词的问题，服务端会直接跳过；带了“最新”之后，又因为后台没配搜索密钥而失败。所以画面上会一排“工具调用失败”。正式录制前要先配好搜索密钥，并部署已经改好的搜索判断，再重拍成功结果。
- **字幕 / 标注**：「联网搜索：本轮无结果，见避坑 27」。不要把失败说成查到了资料。结尾卡片「下一集：管好你的项目和对话」。

1. **“子 Agent 失败”标签**：几乎每个任务在左栏都会多出一个带红色“子 Agent 失败”标签的子线程，项目下会越积越多。原因是项目目录不是 Git 仓库，子 Agent 启动失败，主 Agent 会自己接着做完，结果不受影响。回答里也常出现“子 Agent 未能运行”一句。录制时可打码，或口播“这个标签可以忽略”。偶尔主回复只说一句就停了，发一句“继续”即可。
2. **文档导入要点名工具**：只说“导入到项目文档里”时，AI 会先去跑 shell 命令并请求审批，一次实测还以“子 Agent 失败”结束。写成“请用文档创作工具把这份报告导入到本项目”就能直接走文档工具。
3. **文档修改方案的“预览”和“导出新版本”按钮对 docx 无效**：预览报 `DOCUMENT_CHANGE_SET_BINARY_PREVIEW_UNSUPPORTED`，导出报 `DOCUMENT_CHANGE_SET_FORMAT_UNSUPPORTED`。剧本改为“接受”后在对话里让 AI 导出修订稿。另外，打开修订稿时旧的黄色标注框还会叠在新文档上，录制前先点“结束标注”并关闭旧标签。
4. **数据导入不支持中文表头**：数据集列名只允许英文字母、数字和下划线，任何中文表头的 CSV 都会报 `BRAIN_DATASET_COLUMN_INVALID`，AI 还会在“去 BOM”的 shell 命令上反复请求审批。录制请用英文表头的素材，并建议产品侧修复（把中文表头映射成安全的列 key，保留中文作显示名）。
5. **数据右栏的界面小问题**：数据表格上方的列名和类型挤成一行；“数据导入”页没有样式，文字挤成一团；图表默认画的是 quantity；决策 Flow 标题写成了“软件与自动化 Flow 编排”；Julius 面板的“区域环比”数字没有参考意义（如华东 +1220.5%），不要口播。
6. **量化交易**：
   - 没有项目时，“立即用 Skill 自动模拟”看起来可点，实际是禁用状态，点了没反应；必须先建项目。
   - 每笔 100 股茅台会超出 10 万本金，报 `INSUFFICIENT_CASH`，请用 50 股。
   - 让 AI 对比策略后，组合页会多出同名卡片，且数字与对话不一致（对话说均值回归 +2.24%，卡片 `mt-mean-reversion` 显示 -59.61%）。录制请在让 AI 写笔记**之前**拍组合页。
   - 让 AI 复盘时如果不加“不要翻文件”，它会请求递归扫描目录；拒绝后还会重复请求同一命令（见第 8 条）。
   - 研究笔记正文以原始 Markdown 显示，没有渲染。
7. **视频 / 音乐生成返回 401**：“生成本镜”、配音和“✦ 生成整曲”都报 `Auto 媒体工具失败（401）：Unauthorized`，而普通对话正常。需要确认录制账号是否已开通媒体生成权限；本轮演示窗口使用的是复制过来的登录态，也要排除这个因素。另外，AI 写完视频脚本后右栏不会自动刷新，要切换一次工作台；写入的字段也有错位（英文提示词进了“画面与动作”，画面描述进了“旁白”）。
8. **拒绝审批后会重复请求**：点“拒绝”后，AI 经常原样再请求同一条命令，新发的消息只能排队。遇到时再拒绝一次，排队的消息就会接上。
9. **其他界面问题**：
   - 软件工作台的终端在切换项目后仍停在上一个项目目录，需要点“重新连接”；提示符里的中文路径显示为乱码。
   - “项目文件”页签在 AI 写了 3 个文件后仍显示“项目还没有文件”。
   - AI 写的游戏策划只落到 `design/quick-specs/` 文件里，右栏“游戏策划”编辑器仍是空的。
   - 文档工作台首次进入时，右栏标题可能显示内部名 `__internal_chat__`，要先选好项目再录。
   - 新对话输入框下方的项目选择器写的是英文 “Choose project”。
   - 右栏“项目资源”在普通聊天里也一直显示上一个项目的文件。
10. **权限别误开“完全访问”**：本轮操作中权限曾意外变成“完全访问”。每集开录前看一眼输入框左下角，确认是“替我审批”。
11. **隐私**：设置页“用户名”输入框会显示真实邮箱；左栏历史、钱包余额、本地路径中的真实姓名一律打码，私有 API Key、访问令牌绝不能入镜。
12. **量化合规**：片头片尾必须有“不构成投资建议”字幕，不口播任何收益承诺。
13. **对话进阶**：
    - “目标”只在新对话里生效；在已有对话里点“目标”后发送，和普通消息没有区别。
    - 目标执行过程和其他思考面板会露出英文推理、JSON 和内部提示词（如 “desktop must not curl TokenHub”“server_authoritative_auto”），录制时折叠思考面板或快进。
    - 点停止按钮后，这一轮没有立刻停下，仍然生成完了全文。
    - @ 引用会把被引用对话的整段摘要和最近 5 轮原文塞进用户气泡，画面很长。
    - 回答下方的操作按钮只在鼠标悬停时出现，静态截图里看不到。
14. **项目与对话管理**：
    - 搜索只返回项目里的对话，普通聊天（如“用三句话解释什么是复利”）搜不到。
    - 设置 → 已归档对话的条目描述里露出内部名 `__internal_chat__`。
    - “恢复并打开”后，这条对话没有回到左栏聊天列表。
    - 侧边聊天显示的是另一段对话（暑假阅读清单）的内容，而且是没有渲染的原始 Markdown。
15. **技能**：
    - 在非项目的普通聊天里用 Skill Creator，AI 会回复“已写入并安装”，但磁盘上没有任何文件。必须在项目里，并写明“直接用工具真实写入”。
    - 技能页“已安装”始终是 0 个结果：不显示项目里的 `.newbrain/skills`，也不显示安装专家后附带的技能。
    - “可安装”推荐列表为空（ClawHub 推荐未返回）。
    - 输入框的“选择技能”按钮只在技能列表不为空时出现，所以新手根本看不到它。
16. **插件**：
    - 13 个插件全部是内置且“已安装”，“扣子官方”来源下没有内容，市场里没有可“添加”的插件。
    - 在加号菜单里选一个插件后，输入框没有任何标记；发送后报“所选技能不可用或已禁用：documents”。而且这个选择绑定在对话上、界面上又无法取消（选择器被隐藏），此后这个对话里每条消息都报同样的错，只能新开对话。
    - “已安装”页的调用次数、成功率、平均延迟全部显示“暂无”，即使 AI 刚用 Documents 生成过 Word。
    - “新建插件”预填的是英文 “help me create a plugin”。
17. **自动化**：
    - “新建自动化”没有表单，只是打开一个预填了“请帮我创建一个自动化任务：”的新对话；任务是由本地规则从你发的那句话里解析出来的。
    - 解析规则只认“每天 / 每周 X / 每 N 分钟 / 每小时”加时间；“工作日”会被当成“每天”，“3 分钟后运行一次”这种说法不会生成任务。
    - 任务标题由规则自动起，和内容对不上：“每日简报”模板生成的任务叫“每日项目进度整理”，内容里有“对话”二字就叫“线程跟进提醒”。
    - AI 收到“创建定时任务”的请求时，会去尝试 Windows 系统计划任务（`schtasks`），被安全护栏拦截后以“Agent loop stalled”结束。建议在要求里加一句“不要调用 shell 或系统计划任务”。
    - 点“使用模板”时，如果左栏正选中某个项目对话，模板的那句话会被发进这个项目对话，AI 把它当成“创建技能”去做（实测生成了一个 daily-briefing 技能包）。录制前先点“新对话”。
    - 到点自动运行和“立即运行”都显示“成功”，但看不到结果内容：详情页只有“成功”二字，原对话里也没有新消息。
    - 自动触发后，“下次”时间仍显示刚过去的那个时刻，没有顺延到第二天。
    - 删除确认框的标题是内部包名 `@codex-forge/desktop`。
18. **软件联动**：“刷新窗口列表”报 `Windows UI driver returned invalid JSON`。原因是中文窗口标题在输出里变成乱码，导致 JSON 解析失败。错误信息还会把其他窗口的进程名和标题原样显示出来，存在隐私风险；本轮截图已把这段替换为“窗口数据已省略”。
19. **预览面板**：
    - 在项目上下文里，右栏被“项目资源”占着；要从对话标题栏右侧的“工作区状态”菜单进入审查、终端和侧边聊天，浏览器和文件树只能用快捷键或菜单栏打开，新手很难发现。
    - 浏览器面板的地址栏被挤成一个字母宽，“在安全浏览器窗口打开”几个字竖着排。
    - 非 Git 项目的审查页始终为空，终端里 `git status` 报 not a git repository。
    - 菜单栏“查看”弹出的是系统原生菜单，自动截图拍不到，录屏可以正常拍。
20. **深色主题不完整**：切到深色后，设置页的分类文字和标题几乎看不清，“返回应用”一块变成白底；主界面右栏仍是浅色；账号菜单里的文字看不清。
21. **游戏**：
    - “项目与文件”和“资产与测试”两个页签内容完全相同。
    - “创建 Web 游戏模板”生成的是通用的点击小游戏“青石谷试炼”（点按钮加修为），和已经设计好的关卡、角色没有关系。
22. **品牌与文案残留**：
    - 帮助菜单里的“NewBrain 文档”“新增功能”“故障排除”“发送反馈”分别指向 OpenAI Codex 的文档站和 `github.com/openai/codex/issues`。
    - Git 设置的分支前缀默认是 `codex/`；浏览器设置的说明写着“对齐 Codex 桌面浏览器设置”；外观主题名显示 “Codex”；钱包套餐旁有 “OpenAI” 标签。
    - 个性化的默认系统提示词是英文 “You are a helpful coding assistant…”。
    - 异常反馈的环境信息里字段名是 `codecnVersion`，值为 1.4.30，和账号页显示的软件版本 1.4.27 不一致。

    - 量化“大盘与板块”的大盘指数、行业板块、资金流向都报 `Connection aborted`（RemoteDisconnected），个股行情和 K 线正常。

24. **对话进阶补测**：
    - **分叉答案**：点回答下的“分叉答案”，会复制整条对话而不是从这条回答分叉；在项目对话里生成的“……答案分叉”是空的，原问答没带过来；在普通聊天里点，新对话根本不出现在左栏，画面还会跳到另一条对话。
    - **语音听写不可用**：输入框的麦克风按钮被样式 `display:none` 永久隐藏；设置 → 常规 → 听写的快捷键依赖 Chromium 语音服务，实测拿到麦克风后立即报 `network` 错误，国内网络下无法使用。“听写词典”里残留一条测试数据“6月30日 22:06 Yeah.”。
    - **排队**：排队消息只有“立即发送 / 放回输入框编辑 / 删除”，不能调整顺序。一次排两条都自动发出时，对话里只显示第一条问题，AI 却只回答了第二条，第一条被吞掉。
    - **草稿串线**：在某个对话里输入但没发送的内容（本轮是一条异常反馈），切到别的对话、甚至新分叉出来的对话时又出现在输入框里，容易误发。录制前先清空输入框。
    - 发完第一条后焦点会离开输入框，这时直接打字不会进输入框；录排队时每次先点一下输入框。
25. **项目与对话管理补测**：
    - **在新窗口中打开**：右键菜单的这一项点了没有任何反应。原因是主进程会拒绝同源地址的 `window.open`，这个功能等于失效。
    - **分支**：项目对话里能生成“……本地派生”并带上原问答；普通聊天里点“分支”，新对话不会出现在左栏。“复制”“分支”右侧的“›”像子菜单，实际点了直接执行；“复制”复制的是 `newbrain://` 内部链接，普通用户用不上。
    - **搜索文件**：命令面板里的“搜索文件”（`file:` 前缀）实测搜不到项目中已有的 `SKILL.md`，提示“没有找到匹配的项目、聊天或文件”。普通关键词搜索的结果条目被挤成很窄的一列，标题只剩一个字，还会露出本地完整路径。
    - **导出为 HTML**：保存框默认打开系统“文档”文件夹；导出的网页页头显示工作区内部名 `__internal_chat__`，每条消息时间是 UTC 格式（如 `2026-09-27T12:06:46Z`），比北京时间慢 8 小时。
26. **首页与工作台补测**：
    - 新对话首页三张卡片“连接消息传送 / 连接 GitHub / 连接 Linear”点了都只是跳到设置 → MCP 服务器，没有对应的一键连接流程。
    - 视频时间线顶部露出内部工程号 `project_…`；全片序列显示“总长 00:04:00”，但全片时钟是 00:12:07，两处时长不一致。
    - 文档“审校”页签在接受修改方案后显示“当前文档还没有标注或修改方案”，看不到历史方案。
    - 技能页“已安装”“可安装”点刷新后仍为 0 个结果，技能详情、停用无从演示；插件市场没有可“添加”的插件（同第 15、16 条）。
27. **联网搜索拍不出成功结果**（补测）：
    - 问句里没有「最新 / 今天 / 新闻 / 价格」或股票相关词时，服务端在真正搜索前就判定不需要联网，大约 0.2 秒返回空。界面只显示「工具调用失败」。判断规则已改为这类关键词默认真搜，在 `spring-app` 的 `TemporalQueryPolicy`，重新部署后才生效。
    - 问句里带了「最新」之后，请求会走到搜索供应商，返回 `WEB_SEARCH_PROVIDER_NOT_CONFIGURED：智谱搜索 API Key 未配置`（后台可配 `zhipu-web-search`，或复用已有的 glm 对话密钥）。全网搜索把这句原因丢掉，只显示没有可用来源。
    - 录「让 AI 上网查资料」之前，先在后台配好搜索密钥，并部署上面的判断修复。失败过程不要拍进正片。
    - 政府网站搜索能返回结果，和普通上网查资料不是一回事，不要用来演示咖啡营销这类问题。
