01 / CONTEXT

持续理解项目

对话不再是孤岛。BRAIN 将文件、历史任务、工作台状态和产物串成可延续的项目上下文。

02 / ACTION

真实调用工具

从读取文档、分析数据到执行代码、生成媒体，关键操作经过权限判断、用户审批和可取消任务。

03 / OUTPUT

交付可用产物

输出不仅是文字回答，还包括报告、表格、演示文稿、代码、音视频与可追踪的任务结果。

04 / ROUTING

模型自动路由

Spring 按快速、推理、代码、文档等能力统一路由模型，普通用户无需理解复杂配置。

05 / GOVERNANCE

企业统一治理

服务端集中管理账号、套餐、工作台开关、额度和降级链，兼顾体验稳定与成本可控。

06 / SCALE

跨平台可扩展

公共能力共享，Windows、macOS 与 Ubuntu 保留各自系统适配，能力从桌面端平滑延伸。
