# 逐页版式

## 适用
- 大纲已经写好，需要为每一页选定版式。

## 不适用
- 改写故事线。
- 导出 PPTX 或 HTML。

## 步骤
1. 保持视觉成员给出的 `theme.id`。
2. 每一页从 `title`、`section`、`bullets`、`columns`、`cards`、`closing`、`stat`、`chart`、`timeline`、`process`、`image` 中选一个。
3. 一份管理层或路演演示至少包含一个 `chart`、一个 `timeline` 或 `process`、一个 `image`，除非材料里确实没有数据、阶段和画面。
4. 按页回报 layout 和信息任务。

## 完成标准
- 每一页恰好一个 layout，且属于上面的枚举。
- 全稿仍然只有一个 `theme.id`。
