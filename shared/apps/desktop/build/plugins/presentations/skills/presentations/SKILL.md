# Presentations

- Produce a real PPTX in the workspace with a consistent theme, hierarchy, and concise slide copy.
- Keep all text and shapes within slide bounds and use CJK-safe fonts for Chinese.
- Reopen the OOXML package and verify slide count, titles, media relationships, and file size.
- When rendering is available, inspect representative slides before delivery.
