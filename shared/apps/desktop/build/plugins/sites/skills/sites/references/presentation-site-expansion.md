# 宣传页与落地页

用户要新建落地页、宣传页、作品集首页，或其他以浏览和理解为目的的视觉网站时，按本文件做完。已有业务项目里的普通修改不要套用本文件。

## 做成可浏览的完整页面

把简短需求当成方向，先定下一个具体主题，再补齐结构、内容和页内交互。用户明确要求保留或禁止的内容保持原样。

访客路径要能了解主题、查看具体内容，并走到下一步。每个新增版块必须有独立作用。

不要只堆段落。用版式、图片、动效和交互把这个主题讲清楚。画廊、引语、可交互组件是可选手段，按主题选用，不要当成清单逐项打勾。

保留理解和使用所需要的文字。删掉重复口号，以及只换一句标语的版块。

## 具体、一致、可验证

缺的细节用前后一致的具体内容补上。用户明确标成未知的，保留未知。其余内容要能看懂，并在交给用户的说明里写明哪些是补写的。

页面按访客能直接打开的成品来做。没有接通的外部服务不要写成已经成功。按钮、表单和导航必须在当前页面里真实可用，或者明确标成页内示例。

在当前工作区写出真实的 HTML、CSS 和 JavaScript，入口文件路径要清楚。用新脑子浏览器预览，并检查窄屏、导航、控制台错误、缺失资源和键盘可达性。远程发布必须等用户明确授权。

不要把 `assets/static-site.html` 的单标题模板直接交给用户当成品。
