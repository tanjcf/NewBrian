# Phase 1 Contract

## What We Are Building Now

An operator-facing desktop workbench that can:

- attach to one local workspace
- maintain one interactive coding session
- ask a runtime to inspect files and execute tools
- pause for approval before risky operations
- show proposed patches before apply

## What Makes It Codex-Like

- local project awareness
- tool-using agent loop
- human approval gates
- patch-oriented editing workflow
- persistent task timeline

## What We Deliberately Defer

- private model hosting
- fully autonomous background swarms
- enterprise tenant isolation
- marketplace-grade plugin governance
