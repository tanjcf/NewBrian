# 文档索引（docs）

本目录包含 `NewBrain / Codex Forge` 的产品设计、操作手册与详细设计文档。

## 快速入口

- 产品设计：[`product/overview.md`](./product/overview.md)
- 操作手册：[`manual/operator-guide.md`](./manual/operator-guide.md)
- OpenClaw / ClawHub 技能安装：[`manual/openclaw-skills.md`](./manual/openclaw-skills.md)

- Auto 模型路由（一期）：[`architecture/auto-model-routing.md`](./architecture/auto-model-routing.md)

## 目录结构

```text
docs/
  architecture/   现有：架构概览与阶段边界（Phase 1）
  roadmap/        现有：里程碑与交付阶段
  product/        新增：产品设计（定位、角色、场景、流程、需求）
  manual/         新增：操作手册（安装、运行、常见问题）
  design/         新增：详细设计（模块、协议、数据模型、接口）
```

## 约定

- 本仓库目前偏“可运行的脚手架 + 可落地的边界设计”。文档以 Phase 1 为主，后续阶段作为扩展点描述。
- 文档中的路径以仓库 `windows/` 为根目录（例如 `apps/desktop`）。
